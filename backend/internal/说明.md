# 后端完成摘要（M2 资料库 + M3 Agent 工作区）

## 修编译
- `internal/models/models.go`：新增 `Usage` 类型（原`Workspace.Usage *Usage`引用未定义类型导致编译失败）；并为 `WorkspaceFile` 增加 `Content` 字段、新增 `RefContent` 类型。
- `internal/api/api.go`：`New()` 改为共享单个 `llm.Client` 实例——先用局部变量 `llmClient` 构造一次，再同时赋给 `h.llm` 与 `h.agent`（`agent.NewWorkspaceSvc(llmClient)`）。

## 资料库 M2
- 新增 `POST /api/files/upload`：multipart 解析，存 `DATA_DIR/uploads`（`{id}{ext}`），按扩展名推断 `kind`（`inferKind`），新建并落库 `FileMeta`（`AddFile`）。需 `library:true` 的 Key。
- 新增 `GET /api/files/{id}/content`：文本类（markdown/json/csv/code/text）返回 UTF-8 文本；图片/PDF/Office 返回原始字节，`Content-Type` 按 kind 设置（图片按扩展名映射到正确 MIME，`imageMIME`）。
- `IngestFile` 改真：`ReadContent` 读文件内容 → `rag.Chunk` 分块 → `rag.Service.Ingest` 向量化入库 → `MarkIngested`。种子文件（无磁盘内容）回退到 `demoContents` 示例内容。
- `storage.Store` 新增：`AddFile`、`GetFile`、`ReadBytes`、`ReadContent`、`TouchFile`、`SetWorkspace`。

## Agent 工作区 M3
- 新增 `POST /api/workspaces`：建工作区（id/title/model/refs），`refs` 引用的资料库文件以 `Referenced:true` 挂到文件树（`agent.WithRefs`）。
- 新增 `POST /api/workspaces/{id}/run`：`collectRefs` 收集被引用文件内容 + `rag.Query` 命中 → `agent.Run` 调 `llm.Stream`（mock）→ 生成 `plan.md`/`result.md`（result 携带回复内容）挂到文件树 → 更新状态为 `done`、填充 `usage` 并扣减 Key 额度 → `SetWorkspace` 持久化。
- 路由在 `main.go` 注册：upload/content/workspaces/run 均指向新 handler。
- `agent.WorkspaceSvc` 的 `Run` 签名改为接收 `[]models.RefContent`；新增 `WithRefs` 与 `buildOutputTree`。

## 验证
- `go build ./...` 通过，`go vet ./...` 无告警，`gofmt -l` 无输出。
- 实测请求（`curl`）：apply key（library）→ upload（返回含 `kind` 的 FileMeta）→ content（返回文本）→ ingest（`{ingested:true}`）→ rag/query（命中片段）→ workspaces create（`ws-` 前缀、引用文件已挂树）→ run（状态 `done`、产出 `plan.md`/`result.md` 且 result 含回复文本、`usage` 填充）。
