# 数字分身 Agent「JasperLee」需求书

> 构建一个 React + Go + Agent 技术框架支撑的数字分身 Agent，参照 Codex / Cherry Studio 客户端的交互范式，结合三张 UI 截图进行还原与扩展。

---

## 一、产品定位

**JasperLee** 是一款「数字分身」形态的个人智能助手桌面端应用。它把三个能力融进一个界面：

1. **对话（Chat）** —— 与数字分身闲聊、问答、写代码、执行任务。
2. **资料库（Library）** —— 个人文件 / 知识库的沉淀与检索，由「文件 + RAG」支撑。
3. **Agent 工作区（Workspace）** —— 分身化身 Agent 挂起任务时，**把任务引用的文件挂载到右侧栏**，实现「会话 + 文件上下文」的可视化。

整体参照 Codex / Cherry 的布局：**左侧功能导航 + 中部主工作区 + 右侧上下文/引用面板**，深色科技风。

## 二、技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | React 18 + TypeScript + Vite | 组件化 + 极速冷启动 |
| UI 样式 | Tailwind CSS + 自定义深色主题 | 贴近截图的 Codex 深色质感 |
| 图标 | lucide-react | 与截图图标风格一致 |
| 状态管理 | Zustand | 轻量、可插拔 |
| 后端 | Go 1.26（标准库 net/http + 轻路由） | 高并发、单二进制、易部署 |
| 数据持久化 | SQLite（go-sqlite3 / 或纯 JSON + 文件系统） | 本地优先，免运维 |
| 向量库/RAG | 阿里云 DashVector + 通义 Embedding（免费额度）或本地 BGE 小模型 | 见第五节「RAG 免费 API 评估」 |

- **底部输入框**：占位提示 `输入消息，按 Enter 发送，输入 / 搜索路径或命令，输入 @ 引用文件或会话`；左下角图标（附件/搜索/会话），右下角「默认」档位 + 发送按钮。

### 3.3 截图三 —— Agent 工作区（inkbloom 范式）

- 左侧会话列表（`greeting`，`现有` 分组）。
- 中部对话流：用户请求 → Agent 回复（含 `Response details` 卡片：状态、模型、耗时、输入/输出 token）。
- **右侧栏「文件」面板**：树形文件结构（`agents/greeting-git-integration/` → `smoke_gallery`、`packages`、`docs`、`.env`、`Dockerfile` …），即**工作区引用的文件**。

> **结论**：采用三栏布局 —— 左（导航/会话）、中（主工作区）、右（资料库详情 / Agent 引用文件 / 上下文）。

## 四、核心功能模块

### 4.1 左侧导航 + 置顶新对话（Codex 一致）
- 窄图标栏：`+ 新建`、`聊天`、`资料库`、`空间`、`设置`。
- 主侧栏：`+ 添加智能体`/`新对话` 置顶按钮；下方会话列表（加载自后端）。
- 会话支持：新建、重命名、删除、切换。

### 4.2 JasperLee 数字分身简介（内置 HTML）
- 在「对话/资料库」中内置一份 **JasperLee 个人主页 HTML**，展示：
  - 头像（可上传）、昵称、一句话人设。
  - 技能卡片、作品集、时间线。
  - 数字分身属性（姓名、年龄、MBTI、擅长领域、语音、性格）。
- 该 HTML 同时进入资料库，供 RAG 检索（分身自我介绍的「记忆」）。

### 4.3 资料库（文件管理 + 浏览 + RAG）
- **文件管理**：上传、下载、删除、重命名、移动、搜索、按类型筛选、排序。
- **内置常见格式浏览**：文本、Markdown、图片、PDF、Office（用 `mammoth/xmldom` 或前端 `react-pdf`/`docx-preview` 预览）、代码、JSON、CSV。
- **RAG 支撑**：
  1. 文件入库 → 解析 → 分块（chunking）→ 向量化（Embedding）。
  2. 语义检索（向量 Top-K）+ 可选关键词召回（BM25）混合。
  3. 检索结果注入对话上下文，回答时返回来源引用（文件名/页码/行号）。
- **标签 / 收藏 / 最近访问**。

### 4.4 Agent 工作区（文件挂右侧栏）
- 创建 Agent 任务（`新任务`）。
- Agent 执行时维护一个 **上下文文件集合**：会话引用的文件、Agent 读写/产生的文件。
- **右侧栏「文件」面板**：树形展示工作区文件；支持展开、打开预览、`@ 引用`、把文件拖入对话作为上下文。
- 每个 Agent 回复附带 `Response details`：模型、状态、耗时、输入/输出 token 数、Agent 类型（`/AGENTS:` 模式）。

## 五、RAG 免费 API 评估（重点调研）

| 方案 | 免费额度 | Embedding | 向量库 | 备注 |
|---|---|---|---|---|
| **阿里云 DashVector** | 有免费试用额度 | 搭配通义千问 Text-Embedding-V3 | 云原生向量库 | 国内可用、SDK 完善，推荐 |
| **阿里云百炼（Bailian）** | 新用户免费额度 | 通义 Embedding | / | 提供文本向量化 API |
| **智谱 AI** | 少量免费 token | GLM Embedding | / | 国产 |
| **本地 BGE-M3 (FlagEmbedding)** | 完全免费 | 本地推理 | Chroma/自建 | 零 API 成本、需本地算力 |
| **Chroma / FAISS** | 免费开源 | 需自带 | 本地自建 | 完全离线 |

> **推荐落地**：**混合方案** —— 云上优先使用「阿里云 DashVector + 通义 Embedding（免费试用额度）」；同时保留本地 `BGE-M3 + Chroma` 作为离线兜底，通过统一抽象接口 `EmbeddingProvider` / `VectorStore` 切换，避免绑定单一厂商。最终以实测免费额度为准（新用户通常送有限 token，超量按量计费，需在代码中做额度/开关保护）。

## 六、架构

```
┌────────────────────────────── 前端 (React/Vite) ──────────────────────────────┐
│  Sidebar(导航+会话)   Chat(对话流)   Library(资料库)   Workspace(工作区+右栏文件) │
│                                │ HTTP (REST/SSE/WS)                           │
└────────────────────────────────┼─────────────────────────────────────────────┘
                                 ▼
┌────────────────────────────── 后端 (Go) ──────────────────────────────────────┐
│  api 层：conversations / files / library / agent / rag / avatar                 │
│  ├─ storage：SQLite + 文件系统（数据目录）                                        │
│  ├─ agent：任务编排 + 上下文文件集合（供右栏渲染）                                 │
│  ├─ rag：ingest(解析/分块/向量化) + retrieve(向量+关键词混合)                     │
│  │    ├─ embedding provider: 阿里云 / 本地 BGE（可插拔）                          │
│  │    └─ vector store: DashVector / Chroma（可插拔）                             │
│  └─ avatar：JasperLee 内置简介 HTML + 记忆                                        │
└────────────────────────────────────────────────────────────────────────────────┘
```

## 七、后端 API 设计（草案）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/conversations` | 会话列表 / 新建 |
| PATCH/DELETE | `/api/conversations/{id}` | 重命名 / 删除 |
| POST | `/api/conversations/{id}/messages` | 发送消息（SSE 流式返回） |
| GET | `/api/files` | 文件列表（分页/搜索/筛选/排序） |
| POST | `/api/files/upload` | 上传文件 |
| GET | `/api/files/{id}/content` | 读取/预览内容 |
| POST | `/api/files/{id}/ingest` | 入库（解析+分块+向量化） |
| POST | `/api/rag/query` | 语义检索 |
| GET | `/api/workspaces/{id}/files` | Agent 工作区文件树 |
| POST | `/api/workspaces/{id}/files` | 向工作区挂载引用文件 |
| GET | `/api/avatar` | JasperLee 简介（HTML/JSON） |
| GET | `/api/health` | 健康检查 |

## 八、里程碑

1. **M0 框架**：前后端骨架跑通，三栏布局 + 三个视图可切换。✅（本期）
