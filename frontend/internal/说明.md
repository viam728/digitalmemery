# 前端完成摘要（M2 资料库 + M3 Agent 工作区）

## 类型与 API
- `src/types.ts`：`WorkspaceFile` 增加 `content` 字段；`Workspace` 增加 `usage?`（promptTokens/completionTokens）。
- `src/api.ts`：新增 `uploadFile`（multipart/FormData）、`getFileContent`/`getFileBlob`（拉取原始内容）、`ingestFile`、`createWorkspace`、`runWorkspace`。重构鉴权头：普通 JSON 请求自动加 `Content-Type`，FormData 上传不强加，SSE 单独用 `jsonHeaders()`。

## 资料库 M2（LibraryView）
- 顶部新增「拖拽/点击上传」区（`UploadZone`）：拖放或点击选择文件后调用 `uploadFile`，成功后插入顶部列表。
- 行点击改为 `openFile(id)`：打开右栏 `preview` 模式并拉取文件内容。

## 预览（RightPanel）
- 新增 `PreviewPanel`：按 `kind` 渲染——markdown/代码/JSON/CSV/文本用 `<pre>` 等宽显示（JSON 自动美化缩进）；图片用 `<img>`（`URL.createObjectURL`）；PDF 用原生 `<iframe>`；Office 用占位说明。

## Agent 工作区 M3（WorkspaceView）
- 左栏「新任务」按钮调用 `createWorkspace(title)`，创建后自动打开右栏文件树。
- 主区新增“运行任务”区：文本框输入提示 + 运行按钮（`runWorkspace(id, prompt)`），运行时按钮显示动画并禁用；结束后显示状态（待命/运行中/已完成/出错）、本次 token 用量，并渲染工作区文件树（引用文件标黄「已引用」，产出文件含可预览内容）。
- 右栏复用 `WorkspaceFileTree` 显示 `activeWorkspace.files`。

## 验证
- `npx tsc -b` 通过，`npx vite build` 成功构建。
